\section*{Residue Classes mod 6}

This notebook tests the finite residue constraint
\[
p > 3 \Rightarrow p \equiv 1 \text{ or } 5 \pmod{6}.
\]

For primes below 1,000,000, the measurement gives:
\begin{itemize}
  \item $\#\{p>3\} = 78496$
  \item valid residue count $= 78496$
  \item invalid residue count $= 0$
  \item $CGCS_{mod6} = 1.000000$
  \item $drift_{mod6} = 0.000000$
\end{itemize}

Modulo 6 recovers candidate residue classes, not primes exactly.
